# Unity-TPS-Player

This is the source code for a WIP Player for a Third-Person Shooter game in Unity. It was made for an arcade-style gameplay rather than realism, hence double-jumping and dashing are possible. It is still missing many features, animations, and effects. However, the project is being engineered to be modular and easily scalable.

[Here is a live demo you can play on itch.io](https://nicolas-engles.itch.io/unity-tps-player)
